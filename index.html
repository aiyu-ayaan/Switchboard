Core Capabilities

Engineered for Hardware Control, Low Latency & Local Privacy

VESA MCCS & WMI

Hardware Displays & DDC/CI

Multi-monitor hardware brightness and contrast control. Communicates directly with physical monitors via DXVA2 VESA MCCS and controls laptop displays via WMI.

Explore details →
WASAPI & SMTC

Windows Core Audio Mixer & Media

Independent per-application audio session mixer and master volume control. Live SMTC transport sync with album artwork, playback toggle, and track seek.

Explore details →
X25519 + AES-256-GCM

Zero-Trust E2EE Pairing

Zero-password ephemeral key exchange generated via QR code. All local network packets are authenticated and encrypted with hardware-accelerated AEAD ciphers.

Encrypted P2P File Transfer

Installation & Setup

Get Started with Switchboard

Install Pre-built ApplicationsEnd Users

Download packaged release binaries for Windows (Desktop Host + Daemon) and Android APK. Zero compilation required.

1
Download Desktop Host (Windows)
Get the latest Switchboard Setup (.exe) or portable executable from GitHub Releases and launch it on your PC.
# Download installer or binary from GitHub Releases:
https://github.com/aiyu-ayaan/Switchboard/releases
2
Install Mobile App on Android
Transfer and install the app-release.apk on your Android phone (Android 9.0 Pie / API 28+ required).
# Or install directly via ADB:
adb install -r switchboard-app.apk
3
Connect over Local Network
Ensure both computer and Android phone are on the same Wi-Fi or LAN subnet. Launch the app and scan the QR code displayed on the desktop.
