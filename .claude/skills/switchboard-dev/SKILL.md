## 2. ⚠️ Strict Rules & Enforcement (MANDATORY)

Every contributor and AI assistant working on Switchboard MUST strictly adhere to these rules without exception:

### A. CRITICAL RULE: NEVER PUSH TO REMOTE
> **AI assistants must NEVER execute `git push`, `git push origin`, or any push variant under any circumstances.**
> All commits must remain strictly **LOCAL** on the user's machine. Pushing to remote repositories is exclusively the manual decision and responsibility of the human repository owner.

### B. NO AI ATTRIBUTION
> Never add yourself or any AI model/assistant as author, committer, or co-author.
> Never include tags such as `Co-authored-by: Claude`, `Generated by AI`, or similar annotations.
> The commit author must reflect the configured user (`aiyu-ayaan`).

### C. STRICT COMMIT MESSAGE FORMAT
All commits must follow the conventional commit structure:
```
<type>(<scope>): <short summary>

[optional detailed description]
```

- **Allowed Types**: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`, `perf`, `ci`, `revert`, `build`.
- **Allowed Scopes**: `android`, `desktop`, `backend`, `devdocs`, `docs`, `root`, `crypto`, `system`, `release`, `submodule`.
- **Short Summary**: Written in the imperative mood (e.g., "add feature", not "added feature"), concise, under 72 characters.
- **Keep Commits Atomic**: Break distinct changes into smaller, logical, single-purpose commits.

### D. SUBMODULE DUAL-COMMIT WORKFLOW
When any file inside `development/` is modified:
1. **Prevent Detached HEAD**: Always verify `git branch --show-current` inside `development/`. Ensure you are on the `main` branch (never commit on a detached HEAD).
2. **Submodule Commit First**: Stage and commit inside `development/` on branch `main`.
3. **Parent Repository Commit Second**: From repository root, stage `development` and commit on branch `master`.

### E. DOCUMENTATION INTEGRITY
After each relevant commit, update the documentation in `@devdocs` (`development/devdocs/`) and `docs/docs/`, and keep `development/devdocs/TODO.md` updated with progress.
